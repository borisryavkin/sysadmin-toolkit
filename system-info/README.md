# Linux System Info

A small Linux/Bash system-information utility representing routine systems-administration work from 2015. It prints basic host, kernel, uptime, memory, disk, network, and process details.

## Usage

```sh
chmod +x system-info.sh
./system-info.sh
```

## Requirements

Typical Linux utilities: `hostname`, `whoami`, `uname`, `uptime`, `free`, `df`, `ip` or `ifconfig`, `ps`, and `awk`.

## Notes

Linux/Bash system-administration utilities from early systems-administration work, covering routine diagnostics and automation.
